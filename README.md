# Badminton Game Analysis

A data-analysis project exploring badminton game data through Python, statistical analysis, and visualization.

## 🎯 Objective

Analyze badminton game data to identify patterns and communicate useful insights through exploratory analysis and visualizations.

## 📊 Dataset

The repository includes `badminton_dataset.csv`, an analysis notebook, and an exported PDF report.

## 🔬 Workflow

Data inspection → Cleaning → Exploratory analysis → Statistical investigation → Visualization → Interpretation

## 🛠️ Technology Stack

Python · Pandas · NumPy · Matplotlib · Seaborn · Jupyter Notebook

## 📂 Repository Structure

```text
.
├── Badminton Sport Analysis.ipynb
├── Badminton Sport Analysis.pdf
├── badminton_dataset.csv
└── visualization assets
```

## ▶️ How to Run

Open `Badminton Sport Analysis.ipynb` in Jupyter Notebook or Google Colab and execute the notebook sequentially.
